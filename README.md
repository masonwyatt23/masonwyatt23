## Phantom is the workbench. The ecosystem is the engineering system.

<a href="https://github.com/ashlrai/phantom"><img align="right" width="104" src="https://raw.githubusercontent.com/ashlrai/phantom/master/docs/images/phantom-hero.svg" alt="Phantom engineering workbench"></a>

**[Phantom](https://github.com/ashlrai/phantom)** is our open-source workbench for coding agents and agentic engineering. It brings projects, agent sessions, local models, tools, and guarded fleet workflows into one place—with inspectable work and human control.

Our ambition is bigger than another coding assistant: an engineering system that can take an objective, explore approaches, build and evaluate software, learn from evidence, and improve over time. **That is the direction we are building toward, not a claim that unrestricted autonomy is already shipped.** Resident automation is opt-in, dormant until separately set up and authorized, and currently macOS-only.

```sh
npm install -g @ashlr/phantom
phm --version
phm verse
```

## The open-source engineering ecosystem

Each tool can stand on its own. Together, they give the workbench more of the context and safeguards an engineering system needs.

| Project | Part of the system | Repository |
|---|---|---|
| **Phantom** | Autonomous engineering fleet + workbench: shared queues route work across agent accounts, local models, and remote machines; agents collaborate over a bus; merges and releases run themselves. | [ashlrai/phantom](https://github.com/ashlrai/phantom) |
| **Phantom Secrets** | Local vault, proxy, and MCP tools; supported routes keep managed credentials out of agent context. | [phantom-secrets](https://github.com/ashlrai/phantom-secrets) |
| **Locus** | Identity plane that pins an agent session to the intended account and tenant. | [locus](https://github.com/ashlrai/locus) |
| **Lexicon** | Personal vocabulary that corrects speech-to-text names and technical terms before an agent sees them. | [lexicon](https://github.com/ashlrai/lexicon) |
| **AshlrCode** | Multi-provider coding agent for the terminal. | [ashlrcode](https://github.com/ashlrai/ashlrcode) |
| **Morphkit** | Tooling to turn React and TypeScript apps into native SwiftUI projects. | [morphkit](https://github.com/ashlrai/morphkit) |
| **Ashlr Stack** | CLI and MCP tools for provisioning and connecting development services. | [ashlr-stack](https://github.com/ashlrai/ashlr-stack) |
| **Ashlr Plugin** | Compact engineering tools for Claude Code and Codex. | [ashlr-plugin](https://github.com/ashlrai/ashlr-plugin) |
| **BinShield** | Inspect npm install scripts and native binaries in the software supply chain. | [binshield](https://github.com/ashlrai/binshield) |
| **WebFetch** | License-aware image search for tools and agents. | [webfetch](https://github.com/ashlrai/webfetch) |
| **Ashlr MD** | AI-native Markdown app with MCP integration. | [ashlr-md](https://github.com/ashlrai/ashlr-md) |
